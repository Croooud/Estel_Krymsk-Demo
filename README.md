# «Счастливые люди» — сайт салона Яны Белинской (Крымск), версия 2

Демонстрация для владелицы. Технически закрыта от индексации (`noindex`); в интерфейсе служебных пометок нет.
Прежняя версия сохранена для сравнения в `versions/` (`v1-index.html` открывается двойным кликом).

## Как открыть

- **`dist/index.html`** — один самодостаточный файл (стили, скрипт, фото внутри).
- **`dist/site/`** — версия для хостинга: фото отдельными файлами в `assets/`, адаптивные размеры и отложенная загрузка.

## Как менять

Тексты, контакты, цены, ссылки, кадрирование фото — в `content.json`. Затем:

```bash
python3 build.py          # Python 3 + Jinja2 + Pillow, Node.js + tailwindcss v4
python3 tools/check.py    # автопроверки в Chromium (Playwright) → 168 проверок
python3 tools/shots.py    # скриншоты 360 / 390 / 1440
```

Исходники фото салона положите в `src/originals/` (в архив не включены — это ваши оригиналы).

## Дизайн (по референсу AURELIA, без его содержания)

Тёплая кремовая основа `#F7F3EC`, песочные секции `#EEE5D9`, светлые поверхности `#FFFCF7`, текст `#302B25`, вторичный текст `#665E54` (чуть темнее стартового `#6D655B` ради контраста на песочном), оливковые кнопки `#62683B` / `#51572F`, линии `#DED6CA`. Заголовки — Cormorant Garamond, интерфейс и цены — Manrope с табличными цифрами. Кнопки со скруглением 12 px, фото 22–28 px.

Порядок: шапка → единый hero (бежевая карточка: текст слева, фото справа с мягким переходом; на телефоне текст и кнопка сверху, фото ниже) → полоса из трёх фактов → четыре карточки направлений (ведут в свою группу прайса) → «О салоне» (фото + текст + адрес) → «Услуги и цены» (Мастер / Топ-мастер + четыре аккордеона) → «Наши работы» (галерея) → «Уход продолжается дома» → финальный блок записи и контактов → короткий подвал.

**Запись:** «Записаться» на телефоне сразу звонит (`tel:+79897605460`), на компьютере ведёт к финальному блоку с крупным телефоном. Нижней липкой кнопки больше нет. Когда появится сервис онлайн-записи — заполните `booking.url`.

**Прайс:** одна структура данных, обе категории; переключатель — кнопки с `aria-pressed` и объявлением для скринридера; группы — нативные `<details>` (клавиатура и состояние «раскрыто» работают без доработок). При смене категории открытая группа сохраняется; «Макияж и брови» у «Мастера» скрыты, вместо них ссылка «Показать» в прайсе топ-мастера. Без JavaScript видны цены обеих категорий с подписями.

**Движение:** появление секций 350 мс со смещением 14 px через Web Animations API, наведение на кнопки и карточки. GSAP и Lenis не используются (бриф: без тяжёлых библиотек и перехвата прокрутки); Lenis можно включить флагом `motion.smoothScroll`.

## Галерея работ

Отзыв убран по решению заказчика (один отзыв выглядит неубедительно); его данные остались в `content.json → review` со `showOnSite: false`.

На его месте — раздел «Наши работы». Пока фото нет, показываются четыре спокойные плашки «Стрижки / Окрашивание / Укладки / Уход» и строка «Скоро здесь появятся работы мастеров салона». Чтобы заполнить:

1. Положите снимки в `src/gallery/` (лучше вертикальные, 4:5, от 900 px по ширине; 4 или 8 штук).
2. Перечислите их в `content.json → gallery.photos`: `{"source": "cut-01.jpg", "crop": null, "width": 900, "alt": "Женская стрижка каре", "caption": "Стрижка"}`.
3. `python3 build.py` — плашки сменятся фотографиями, по нажатию фото открывается крупнее (Escape закрывает).

Чтобы спрятать раздел до появления фото — `gallery.showEmpty: false`. Только реальные работы салона с согласия клиентов, без стоковых снимков.

## Главное изображение — ограничение

Предпочтительный вариант — атмосферный beauty-портрет. Он сгенерирован в вашем Canva (медиа `MAHZYk2-fWc`), но в рабочую среду пришло только превью 161×200 px, а скачать полный размер оттуда нельзя. Поэтому сейчас стоит **запасной вариант из брифа — реальный зал салона с зелёной стеной**.

Чтобы поставить портрет: скачайте его из Canva, положите в `src/originals/`, в `content.json → images.hero` укажите `source`, `crop: null`, `width` (≈1100), новый `alt` и `kind: "mood"`, пересоберите. Портрет нельзя подписывать как Яну, сотрудницу, клиентку или работу салона. В шаблоне подписи у hero нет.
